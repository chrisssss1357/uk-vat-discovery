# UK VAT Identifier Discovery

## 1. Prezentarea proiectului

Acest proiect urmărește să investigheze în ce măsură numerele de înregistrare în scopuri de TVA ale companiilor din Regatul Unit pot fi identificate folosind surse de date disponibile public.

## 2. Obiectivul proiectului

Obiectivul principal este identificarea unor posibile numere de înregistrare în scopuri de TVA, verificarea acestora prin intermediul serviciilor oficiale HMRC și evaluarea corectitudinii rezultatelor obținute.

## 3. Tehnologii utilizate

- Python – prelucrarea și analiza datelor;
- Git – gestionarea versiunilor codului;
- GitHub – găzduirea proiectului;
- SQLite – stocarea și organizarea datelor.

## 4. Metodologie

Proiectul va analiza mai multe surse publice de informații, va identifica posibile numere de TVA și va verifica dacă acestea aparțin companiilor corespunzătoare.

Vor fi documentate atât sursele care oferă rezultate utile, cât și cele care nu permit identificarea unor informații relevante.

## 5. Stadiul proiectului

Configurarea inițială a proiectului a fost finalizată.

Următoarele etape vor include cercetarea surselor de date, construirea unui eșantion de companii și dezvoltarea unui proces de identificare și verificare a numerelor de TVA.
